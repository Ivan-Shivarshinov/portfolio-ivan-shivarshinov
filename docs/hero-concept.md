## Обоснование

Выбор дефолта отвечает критериям D-14:

**(a) Реализуемость в системе (токены / сетка / CSS-only).** Композиция целиком собирается из
существующих элементов системы: моно-метка (BaseLayout, D-05), `--text-display` (clamp, токен
02-03), `--space-xl`-ритм, Button с `density='lg'`. Ноль клиентского JS (AC R5), ноль новых
зависимостей; любые будущие правки остаются в рамках единого файла токенов и scoped-стилей
(check-tokens, R1/R2).

**(b) Соответствие «Calm Interface, Active Work».**
- нейтральный покой: на первом экране — только нейтральные цвета (bg/ink), ноль декоративных
  заливок; акцент появляется в точках взаимодействия (hover/focus CTA, D-08, SC3);
- моно-слой как системный признак: метка «01 / HOME» задаёт язык «номеров и подписей» (D-05);
- контраст состояний: тишина покоя усиливает единственное первичное действие «Смотреть работы».

**(c) Задел под фазу 3 (контент ложится без перекомпоновки оболочки).** Формула обещания и
подписи (REQ-main-promise) добавляются в фазе 3 как текст под именем — в существующую
вертикальную колонку hero (gap-токены), без изменения каркаса; CTA остаётся финальным
действием секции. Структура index.astro (BaseLayout + hero-shell) не перекомпонуется.

## Статус макета

Макет/концепты — **референс, не источник правды** (D-15). Единый источник истины — файлы
Astro в Git (ADR «Техническая стратегия портфолио Astro + AI-агент + Stacki»: «единый источник
истины — файлы Astro в Git»). Если в будущем появятся Figma-концепты: они архивируются в этом
документе как референс, невыбранные остаются в Figma; все изменения вносятся в код (Git), макет
после переноса не является источником правок (prohibition фазы, статус resolved).
