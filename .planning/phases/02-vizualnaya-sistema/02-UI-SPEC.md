# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** Phase 2 implements the visual system «Calm Interface, Active Work» in code: token extensions (bp, lead/caption, fluid display, easing set), styled shell on all 5 pages, 8 reusable components + 10 inline SVG icons, CSS-only interactive states, project-accent theme contract, Media wrapper, reduced-motion baseline, verification scripts, and 2–3 Figma hero concepts (R9). Real content, images and JS motion — phases 3/5. Locked upstream: `02-SPEC.md` (9 requirements, 14 AC), `02-CONTEXT.md` (D-01…D-16), `01-UI-SPEC.md` (token names, baseline values, accent reservation from phase 2+).

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, nav hit-area padding (narrow) |
| lg | 24px | Section padding, container gutter (mobile) |
| xl | 32px | Layout gaps, container gutter (desktop) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: **1px** — borders/outlines only (Media frame, nav separators, footer top border, empty-state frame; focus ring 2px) — outside scale by explicit contract (phase 1 precedent). Touch targets: nav links at <768px get vertical padding `--space-md` → ≥44px hit area (in-scale; no exception needed). Values locked from 01-UI-SPEC / tokens.css — no changes this phase.

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Display | `clamp(28px, 5vw, 40px)` | 600 | 1.2 | Unbounded | Hero name, page-level statements; fluid (R1) |
| Heading | 20px | 600 | 1.2 | Unbounded | SectionHeading titles, ProjectCard titles |
| Lead | 18px | 400 | 1.5 | Manrope | Intro paragraphs, secondary hero line (consumed with content — phase 3) |
| Body | 16px | 400 | 1.5 | Manrope | Default text |
| Label | 14px | 400 | 1.4 | JetBrains Mono | Nav labels, buttons, tags, page labels, empty-state captions |
| Caption | 12px | 400 | 1.4 | JetBrains Mono | Media captions, footer line |

- Weights: exactly 400 and 600 (mono layer: 400 only). No other weights.
- 6 sizes — the 3–4-size default is overridden by SPEC R1 (lead/caption steps locked; display fluid via clamp).
- Mono is a semantic layer (indexes, roles, dates, statuses, technical data) — never body copy.
- Buttons and tags use mono labels (14px): the technical layer extends to actions — system consistency with «номера и подписи».
- Display range (researcher decision, Claude's Discretion): `clamp(28px, 5vw, 40px)` — preserves the 32px baseline in the ~600–700px viewport range; at 320px «Шиваршинов» (11 chars ≈ 231px) still fits one line in the 272px content column.
- Lead/caption exact values (SPEC "~18px / ~12px"): 18px and 12px.

## Motion

| Token | Value | Usage |
|-------|-------|-------|
| `--motion-fast` | 150ms | Hover/focus color shifts (links, nav, tags) |
| `--motion-base` | 250ms | Border/shadow transitions (cards, media, buttons) |
| `--motion-slow` | 400ms | Larger layout transitions |
| `--ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | Default for interactive transitions |
| `--ease-enter` | `cubic-bezier(0, 0, 0.2, 1)` | State appears (reveal/fade-in) |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | State disappears (fade-out) |

- All transitions in components use `var(--motion-*)` + `var(--ease-*)` only (grep-verified, R4 AC). No literal durations/curves in components.
- Interaction contract (CSS-only, R4):
  - **Links:** color ink→accent; 1px underline appears (offset 2px); fast + standard
  - **Buttons:** primary hover — accent darkened via `color-mix` with ink (≈8%); secondary hover — border→ink, text→accent; pressed — `translateY(1px)`; fast + standard
  - **Nav:** inactive muted→ink on hover; active stays accent; fast + standard
  - **Tags:** border/color→ink on hover; fast + standard
  - **ProjectCard:** on hover border line→ink-muted, title ink→accent; base + standard
  - **Media:** frame border line→ink-muted on hover (when interactive); base + standard
- `prefers-reduced-motion`: all transitions 0ms in every interactive state (global.css media query) — full static state (AC R4, design SPEC §08).
- Phase 2 is CSS-only: no client JS — 0 `<script>` tags in built pages (AC R5). JS motion reserved for phase 5 (ADR order).
