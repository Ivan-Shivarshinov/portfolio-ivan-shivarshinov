## Lumos Framework (дополнительная область по запросу пользователя)

| Option | Description | Selected |
|--------|-------------|----------|
| Как референс принципов | Не импортировать код; перенять организацию токенов; locked-решения сохраняются | ✓ |
| Импортировать Lumos | Требует пересмотра P1 (запрет utility-first), bp-шкалы, check-скриптов | |
| Отложить до фазы 6 | Зафиксировать в Deferred, вернуться при пересмотре ADR | |

**User's choice:** «Как референс принципов» (рекомендованный)
**Notes:** Пользователь предложил импорт Lumos как «набор правил для работы с кодом» (предположив, что его автор — тот же, что у Stacki). Проверка по первоисточникам: Lumos — utility-class CSS для Webflow (color/layout/spacing.css, классы `[class*="..."]`, bp 480/768/992, MIT, Timothy Ricks); репозиторий flowtricks/stacki не упоминает ни Timothy Ricks, ни Lumos — связь авторства не подтверждается. Конфликт с locked-решениями: P1 фазы 1 (utility-first запрещён), bp 768/1200 (R1), единый файл токенов. Итог — D-16: референс принципов без кода; пересмотр — фаза 6.
