## Spacing Scale

Locked from `tokens.css` / 01-UI-SPEC (unchanged this phase):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, tag padding |
| md | 16px | Default element spacing, hit-area padding (nav, footer links) |
| lg | 24px | Section padding, container gutter (mobile), list indent in prose |
| xl | 32px | Layout gaps, hero column rhythm |
| 2xl | 48px | Major section breaks (case page sections, About/Lab block rhythm) |
| 3xl | 64px | Page-level spacing |

Exceptions: **1px** — borders/outlines only (existing precedent: footer top border, media frame, card border). **2px** — focus ring and underline offset (existing precedent). No new exceptions this phase.

Touch targets (in-scale, no exceptions needed): footer contact links at <768px get padding-block `--space-md` → ≥44px hit area (same pattern as Nav, 02-UI-SPEC); the email copy button uses Button `density="lg"` (16/24 padding → ≈52px hit area) so the first interactive control meets touch targets without raw values.
